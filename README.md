# 爱美 · Aimei

Android 实时试衣应用，主要功能接入 Anywear 手机实时试衣，并提供私人衣橱。

## 当前状态

仓库初始化完成；现有 v0.5 源码尚未上传。APK 编译与手机实测完成之前，不视为可交付版本。

## 上传现有源码

将 `Aimei_Anywear_Android_v0.5.0_Source.zip` 原样上传到仓库根目录，无需解压。也可以上传解压后的 Android 工程。

上传后，Android APK 工作流会自动识别工程并执行构建；成功时在 Actions 对应运行页提供 APK、SHA256 和源码包。

## 验证范围

构建成功仅代表编译通过。摄像头授权、Anywear 服务连接、服装选择和实时换装仍需 Android 真机验证。
